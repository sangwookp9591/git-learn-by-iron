CHAPTER 01 · 변경 기록

변경한 파일을 커밋해 보세요

작업 파일 중 다음 기록에 포함할 변경을 선택합니다. 스테이징 영역을 확인한 뒤 커밋을 남기세요.

현재 할 일

git add hello.txt로 파일을 스테이징합니다.

50%

소스 컨트롤

main
  • hello.txt+ 스테이징됨
  • README.mdM 수정됨
  • config.json! 충돌
  • notes.txt? 미추적

변경한 내용과 이유를 한 문장으로 적으세요.

스타일 확인용 예시입니다. 실제 Git 저장소는 변경하지 않습니다.

커밋 그래프

커밋 3개
  1. 9a41c8e인사말 추가HEAD · main
  2. 5bf0d72파일 이름 정리
  3. 2ca601f학습 저장소 시작
